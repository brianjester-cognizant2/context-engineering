# **Module 7: The Frontier**

This module looks at where the field is heading. We cover multi-modal and computer-using agents, the standards and protocols that consolidated in 2026, and the business and ethical questions that arrive once systems act on their own.

The unifying architectural capstone that used to close this module has moved — and grown — into [**Module 8: Agentic Engineering**](../Module8/).

### **By the end of this module you will be able to:**

1. Design multi-modal retrieval and reason about the token cost of images
2. Place MCP, A2A, AGENTS.md, and Agent Skills in their distinct roles
3. Assess meta-agents and self-improving systems, including their failure modes
4. Assign accountability for an autonomous system's actions

**Estimated time:** 2-3 hours, including the hands-on tasks.
