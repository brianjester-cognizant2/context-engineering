# **Module 8: Agentic Engineering**

This capstone module covers the discipline that emerged once teams started running agents in production and discovered that the model was rarely the bottleneck. We cover the **harness** that wraps a model, the **loop** that drives it, the **team structures** that coordinate several of them, and finally a unifying architectural blueprint that organizes every technique in this course.

This module replaces the earlier "Context Window Architecture" capstone. Its central idea — that context assembly is a deliberate design act — survives here as one plane of a larger model.

### **By the end of this module you will be able to:**

1. Name the five layers of a harness and what each one prevents
2. Design a loop with a verifiable goal and guardrails that make runaway impossible
3. Choose an orchestration pattern and write a handoff contract
4. Specify a complete agentic system across six planes

**Estimated time:** 4-5 hours, including the hands-on tasks.
