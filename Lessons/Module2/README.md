# **Module 2: Advanced Prompting Techniques**

This module covers the craft of prompt engineering — the discipline that sits inside context engineering. We dissect the anatomy of a system prompt, cover the in-context learning techniques that control output format and nuance, and look at the reasoning and structured-output strategies that make model output reliable enough to build software on.

### **Lessons**

*   [**Lesson 1: The Anatomy of an Advanced Prompt**](./Lesson1_Anatomy_of_an_Advanced_Prompt.md)
*   [**Lesson 2: Foundational Prompting Techniques**](./Lesson2_Foundational_Prompting_Techniques.md)
*   [**Lesson 3: Advanced Prompting Strategies**](./Lesson3_Advanced_Prompting_Strategies.md)

---

### **By the end of this module you will be able to:**

1. Write a system prompt with a clear persona, few checkable rules, and explicit constraints
2. Choose between zero-, one-, and few-shot, and recognize when examples hurt
3. Enforce structured output with a schema rather than a request
4. Decompose a task so failures are localizable

**Estimated time:** 2-3 hours, including the hands-on tasks.
