# **Module 1: Foundations of Context Engineering**

This module lays the groundwork for the entire course. We explore what "context" is, why it is the critical constraint on building reliable AI applications, the economics that govern every design decision, the principles of effective context design, and a map of how the field is organized.

### **Lessons**

*   [**Lesson 1: What is Context and Why is it Critical?**](./Lesson1_What_is_Context.md)
*   [**Lesson 2: The Evolution and Economics of Context**](./Lesson2_Evolution_and_Economics.md)
*   [**Lesson 3: Core Principles of Effective Context Design**](./Lesson3_Core_Principles.md)
*   [**Lesson 4: The Four Disciplines — A Map of the Field**](./Lesson4_The_Four_Disciplines.md)

---

### **By the end of this module you will be able to:**

1. Explain what context is, and why context engineering is a runtime discipline rather than an authoring one
2. Cost an agent run, including prompt caching and model routing
3. Apply the five design principles, and calibrate an instruction's altitude
4. Diagnose which of the four disciplines a given problem belongs to

**Estimated time:** 3-4 hours, including the hands-on tasks.
