# **Module 6: Evaluation, Testing, and Security**

This module covers the last mile of production AI. We learn to evaluate RAG quality *and* agent trajectories, to debug non-deterministic systems from traces, and to secure systems whose most serious vulnerability — indirect prompt injection — has no prompt-level fix.

### **Lessons**

*   [**Lesson 1: Evaluating Context Quality and Agent Performance**](./Lesson1_Evaluating_Context_Quality_and_RAG_Performance.md)
*   [**Lesson 2: Testing, Tracing, and Debugging**](./Lesson2_Testing_Tracing_and_Debugging.md)
*   [**Lesson 3: Security for Agentic Systems**](./Lesson3_Security_for_Context-Aware_Systems.md)

---

### **By the end of this module you will be able to:**

1. Evaluate retrieval and generation separately, and score an agent's trajectory
2. Calibrate an LLM judge and size an eval set honestly
3. Debug from a trace by finding the divergence point
4. Design an agent's security around capability rather than persuasion

**Estimated time:** 4-5 hours, including the hands-on tasks.
